Tích hợp hệ thống Thi đua sẵn có

Kết nối tới hệ thống quản lý/thống kê Thi đua (Google Apps Script) đang chạy riêng, để đồng bộ dữ liệu vào tab Thi đua thay vì nhập tay lại. Xem chi tiết phương án ở ghi chú bên dưới.

Cách hoạt động: hệ thống Thi đua hiện có (Code.gs) cần mở thêm một nhánh doGet trả JSON (không đổi gì ở giao diện/luồng email hiện tại), ví dụ:
if (e.parameter.api === 'competitions') { var r = getPrograms({}); return ContentService.createTextOutput(JSON.stringify(r)).setMimeType(ContentService.MimeType.JSON); }
Sau khi triển khai lại (New deployment) và dán URL vào ô trên, nút "🔄 Đồng bộ" ở tab Thi đua sẽ gọi JSON này, ánh xạ các trường (tên, ngân sách/đã trả, trạng thái, poster, link Drive...) vào đúng cấu trúc dữ liệu Thi đua của PTVH, và tự thêm/cập nhật theo mã chương trình gốc — không tạo trùng.
